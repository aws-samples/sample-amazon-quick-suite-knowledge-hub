# Branding and Design System

Lookup data for rendering company-branded documents. The default brand is a
generic sample ("AnyCompany Manufacturing"). To rebrand, change the color
tokens below and the company name. There is no logo image; the brand is shown as
a styled text wordmark. The agent reads these values when it builds HTML or DOCX
output.

## Brand identity

- Company name: AnyCompany Manufacturing
- Wordmark: render the company name as styled text in Brand Red. There is no logo
  image. Place the wordmark top-right for quotes and invoices, bottom-right for reports.
- Confidentiality line: "Company Confidential (c) 2026 AnyCompany Inc. All rights reserved."

## Color palette

| Token | Hex | Use |
|-------|-----|-----|
| Brand Red | `#D22630` | Primary accent, top stripe, section titles, wordmark |
| Brand Red (alt) | `#D32F2F` | Accent stripe variant |
| Secondary Red | `#B71C1C` | Hover, darker accent |
| Brand Blue | `#0071B3` | CTAs, links, interactive elements |
| Secondary Blue | `#007BC2` | Secondary CTA |
| Dark | `#1D1D1D` | Header backgrounds, primary headings |
| Body Text | `#303030` | Body copy |
| Subtle Text | `#535353` | Captions, labels |
| Light Background | `#F7F7F7` | Alternating rows, meta panels |
| Border | `#E0E0E0` | Dividers, table borders |
| Success Green | `#468254` | Approved, compliant, healthy margin |
| Warning Amber | `#B8860B` | Review needed |
| Alert Red | `#C62828` | Rejected, critical, margin below floor |

## Typography

- Font stack: `"Inter", Helvetica, Arial, sans-serif`
- Document title: 24-28px, bold, Dark
- Section header: 11-14px, uppercase, letter-spacing 1-1.5px, Brand Blue or Brand Red
- Body text: 13-14px, Body Text color
- Numbers and IDs: monospace (`"SF Mono", "Fira Code", Consolas, monospace`), amounts right-aligned, totals bold

## Layout

- Max width 800px (documents) or 900px (dashboards), centered with `margin: 0 auto`
- Header: white background, 4px Brand Red top stripe, title left, wordmark right
- Content: white, 40px padding
- Footer: Light Background, confidentiality line plus "Generated by Supply Chain Operations" and the date
- Print: include an `@media print` block that keeps tables intact and preserves page breaks

## Status badges

Rounded pills, white text on a colored background:

- Approved / compliant / healthy: Success Green
- Review / conditional: Warning Amber
- Rejected / critical / non-compliant: Alert Red
- Informational / escalate: Brand Blue
